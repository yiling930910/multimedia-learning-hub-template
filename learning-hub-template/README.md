# 多媒體學習站期末專題範本

本範本供助教發布後由學生各組複製。網頁入口為 `index.html`，作業摘要在 `requirements.html`，從複製、編輯到發布的教學在 `github-guide.html`。各人編輯 `section-1.html` 至 `section-6.html`；資源及分工分別在 `resources.html` 與 `contributions.html`。這些檔案是提示，學生須替換並查證內容。

## 助教發布

1. 在 GitHub 建立公開 repository，將本資料夾**裡面的檔案**上傳至 repository 根目錄，commit。
2. 在 Settings 勾選 **Template repository**，把 repository 網址提供給學生；學生按 Use this template 建立各組自己的 repository。
3. 若也要展示範本網站，在 Settings → Pages 選 Deploy from a branch，選 main 和 /(root)，儲存後等待發布。
4. 老師公布期限及指定題目後，更新 `requirements.html`；本摘要不能取代原始指示。

可直接在瀏覽器開啟本地 `index.html` 預覽。網站為靜態 HTML，不需安裝套件或執行程式。
