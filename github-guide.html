INTRODUCTION TO MULTIMEDIA COMMUNICATIONS

GitHub 與網站發布教學

首頁作業要求GitHub 教學資源庫分工紀錄

一、先取得自己的範本

  1. 登入 GitHub，打開助教提供的範本 repository 網址。
  2. 按 Use this template → Create a new repository，選擇帳號、填入 repository 名稱（例如 multimedia-team-01），選 Public，建立 repository。每組建立一份。
  3. 若沒有 Use this template，請助教先在範本 repository 的 Settings 勾選 Template repository；也可下載範本檔案後建立新 repository 上傳。
  4. 組長在 Settings → Collaborators 邀請組員，組員接受邀請後合作編輯。

二、直接在 GitHub 編輯與 commit

  1. 開啟自己的 repository，點選 index.html，再按鉛筆圖示。
  2. 在 HTML 標籤之間填入文字；先修改首頁與負責人，再各自編輯 section-1.html 至 section-6.html。修改標題、連結和資源時保留標籤結構。
  3. 按 Commit changes，輸入簡短修改說明，再確認 commit。Commit 是將這次修改記錄到 repository。
  4. 圖片可從 repository 的 Add file → Upload files 上傳，再依檔案路徑插入頁面。不要把私密資料或密碼上傳至公開網站。

也可用本機 Git：先 git clone <repository URL>，修改後依序執行 git add .、git commit -m "Update project"、git push。開始編輯前先 git pull，並與組員協調，避免同時修改同一段。

三、發布 GitHub Pages

  1. 進入自己的 repository → Settings → Pages。
  2. 在 Build and deployment 的 Source 選 Deploy from a branch；Branch 選 main，資料夾選 /(root)，按 Save。
  3. 等待部署完成，重新整理 Pages 設定頁，開啟顯示的網站網址。網址通常是 https://帳號.github.io/repository名稱/；實際網址以設定頁為準。
  4. 用無痕視窗開啟網址，逐頁檢查圖片與連結；往後 commit 到 main 後等待重新部署，再檢查更新。

若沒有看到網站，確認 repository 可公開使用 Pages、分支為 main、根目錄有 index.html，並檢查 repository 的 Actions 部署狀態。GitHub Free 通常使用公開 repository 發布。

四、繳交前

刪除或替換所有範本提示，完成每人頁面、資源庫與分工紀錄；在課程平台繳交 Pages 網站網址與老師要求的小組資訊。

參考：GitHub Pages 官方設定；使用範本建立 repository。
